# Bouncing DVD Logo

## About the Project
Bouncing DVD Logo is a Python mini project that recreates the classic DVD screensaver animation in a terminal.

The DVD logo moves continuously inside a rectangular boundary, bouncing off the walls and changing colours upon collision.

## Features
- Animated ASCII DVD logo.
- Random starting movement direction.
- Random colour changes after wall collisions.
- Wall and corner bounce counters.
- 30-second animation duration.
- Real-time display of remaining time.

## Technologies Used
- Python
- sys module
- time module
- random module
- ANSI escape sequences

## Concepts Demonstrated
- Functions and loops
- Conditional statements
- Lists and variables
- Randomisation
- Collision detection
- Exception handling
- Terminal cursor control

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run the following command:

```bash
python bouncing_dvd_logo.py
```
